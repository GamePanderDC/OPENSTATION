# Установка OpenStation Max

**USB-прошивка приостановлена:** после установки сообщалось о циклической перезагрузке. Команда `amlmmc enc` в завершающем этапе вернула ошибку; причина ещё выясняется. Не используйте текущий установщик для новой прошивки до проверки способа восстановления. Не стирайте ключи и не выполняйте повторную запись разделов для диагностики.

Последняя сборка автоматически переводила станцию из BootROM в режим записи, скачивала ROM v1.5.1, проверяла SHA-256 и записывала `vbmeta`, `vendor`, `system`. Затем выполнялся `service_flash/after_ubt.bat`; команды после ошибки продолжались, а итог показывал ошибку.

В PR #3 завершающий сценарий отличается: он также записывает раздел `misc`. Имеющиеся варианты `misc` содержат фиксированные параметры загрузки, ревизию и идентификаторы другого устройства. Записывать их на станцию без проверки совместимости и сохранения исходного раздела нельзя. Автор PR проверял завершающий сценарий с имитацией USB; успешная полная запись и загрузка станции в PR не подтверждены.

Сборка установщика на Windows: `powershell -ExecutionPolicy Bypass -File scripts/build_installer.ps1`. Автоматические проверки протокола: `python -m unittest discover -s service_flash/tests -v`. Они используют имитацию USB-устройства и не подтверждают прошивку физической станции.
