# Установка OpenStation Max

**USB-прошивка ещё проверяется:** после версии 1.2 сообщалось о циклической перезагрузке и ошибке `amlmmc enc`. Причина не подтверждена; проверенной процедуры восстановления пока нет. Не стирайте ключи и не перезаписывайте разделы для диагностики.

Начиная с версии 1.4 установщик проверяет контрольную сумму и записывает встроенный `misc_00053.img` на все ревизии 0008, 00052 и 00053 по указанию пользователя. Затем выполняется `after_ubt`; при ошибке записи `misc` команды продолжаются, но итог сообщает об ошибке. Этот образ содержит фиксированные параметры загрузки, номер ревизии 5 и идентификаторы другого устройства. Совместимость и загрузка после такой записи не проверены на физической станции.

Сборка установщика на Windows: `powershell -ExecutionPolicy Bypass -File scripts/build_installer.ps1`. Автоматические проверки: `python -m unittest discover -s service_flash/tests -v`. Они используют имитацию USB и не подтверждают прошивку станции.
