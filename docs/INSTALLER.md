# Установка OpenStation Max

По сообщению владельца проекта пользователи подтвердили работу установщика. Ранее в версии 1.2 сообщались бутлуп, ошибка `amlmmc enc` и прерывание записи; на доступной мне станции полная USB-прошивка не проверялась.

Начиная с версии 1.4 установщик проверяет контрольную сумму и записывает встроенный `misc_00053.img` на все ревизии 0008, 00052 и 00053 по указанию пользователя. Затем выполняется `after_ubt`; при ошибке записи `misc` команды продолжаются, но итог сообщает об ошибке. Этот образ содержит фиксированные параметры загрузки, номер ревизии 5 и идентификаторы другого устройства. По сообщению владельца проекта установщик работает у пользователей; самостоятельная проверка загрузки после такой записи не проводилась.

Сборка установщика на Windows: `powershell -ExecutionPolicy Bypass -File scripts/build_installer.ps1`. Автоматические проверки: `python -m unittest discover -s service_flash/tests -v`. Они используют имитацию USB и не подтверждают прошивку станции.
